# The Cutaway manual

Cutaway records every camera to its own file, lets you switch and stream
the show live, and hands the whole thing to your editor afterwards. This
manual is for the version it came with; each page covers one part of the
show.

**New here?** Start with [Your first hour](first-hour.md), then open
Cutaway and follow its first-show guide.
