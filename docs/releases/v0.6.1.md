## Download

| For | File |
|---|---|
| Mac with Apple Silicon (M1 or later), macOS 13 or newer | **Cutaway-0.6.1-macos-arm64.zip** |
| Windows 11, 64-bit | **Cutaway-0.6.1-windows-x64.zip** |
| Stream Deck (Mac or Windows) | **Cutaway.streamDeckPlugin** |

The apps aren't signed yet, so the first launch takes one extra step. **Mac:** unzip, move Cutaway.app to Applications and open it; when macOS refuses, open System Settings → Privacy & Security and choose **Open Anyway**. **Windows:** unzip anywhere and run Cutaway.exe; when Windows says it "protected your PC", choose **More info → Run anyway**.

Settings, shows and recordings carry over from 0.6.0. The Stream Deck plugin hasn't changed.

## New in 0.6.1

**NDI when you need it**
- Choosing NDI (a source, NDI output, or a show that uses it in the pre-show check) on a computer without it now offers **Install NDI…**: Cutaway downloads NDI's free runtime from NDI and opens its installer. Once it's installed, Cutaway picks NDI up and starts the NDI sources and output that were waiting, without a restart.

**Fixes**
- Clearing finished uploads (or retrying one) while another was uploading could close Cutaway. It can't now.
- Going back a segment after removing segments from a running rundown could close Cutaway.
- The update notice shows what's new as plain text, not the download table.

**Lighter and quicker**
- Only the cameras a frame actually shows (on air, in preview, on the multiview, in the vertical version) are copied to the graphics card for it, which saves a lot with several 4K cameras.
- Cameras open side by side when Cutaway starts or settings change, so the window is back sooner.
- The turning test pictures take a fraction of the work they did.
- With the remote, OSC and MIDI all off, Cutaway no longer prepares their updates.

The full guide is in the [README](https://github.com/braydenm32/cutaway#readme).
