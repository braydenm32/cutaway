The apps aren't signed yet, so the first launch takes one extra step. **Mac:** unzip, move Cutaway.app to Applications and open it; when macOS refuses, open System Settings → Privacy & Security and choose **Open Anyway**. **Windows:** unzip anywhere and run Cutaway.exe; when Windows says it "protected your PC", choose **More info → Run anyway**.

Settings, shows and recordings carry over from 0.6. The Stream Deck plugin hasn't changed.

## New in 0.7.0

**Change sources mid-show**
- Add, remove or change video sources and audio inputs while recording or live. Only what changed opens or closes; every other camera, the program, the mixes, the recording and the stream carry on without a blink, and scenes keep pointing at the right sources however the list moved.
- Removing a source or input while recording or streaming asks first, and warns if it's on the program right now.
- A source removed mid-take ends its own file there (sound included), and the Final Cut, Resolve and Premiere timelines know it ends early. One added mid-take is in the program straight away and gets its own file from the next take.
- Only the program's size and frame rate still need recording and streaming stopped.

**No more waiting window**
- Cutaway's window opens straight away. While the cameras come up, the monitors show a clapperboard, a take number and a line from the studio floor ("Quiet on set!", "Hold for picture…", "Still in make-up.").

**Settings, condensed and explained**
- Twenty-three pages are now six groups (Inputs, Sound, Look, Show, Output, General), each with its pages as tabs.
- Less-used parts of a page fold away and show how they're set while folded: Recording's formats, editing extras and podcast; Switching's stinger, fade to black, replay and automatic switching; the headphones, ducking, talkback and outputs in Mixing; PTZ and picture adjustments for a source; and more.
- Every setting explains itself: hover its name, or its ⓘ, for what it does and when to change it. The long paragraphs that used to fill each page have moved there.

**NDI when you need it**
- Choosing NDI (a source, NDI output, or a show that uses it in the pre-show check) on a computer without it now offers **Install NDI…**: Cutaway downloads NDI's free runtime from NDI and opens its installer. Once it's installed, Cutaway picks NDI up and starts the NDI sources and output that were waiting, without a restart.

**Fixes**
- Clearing finished uploads (or retrying one) while another was uploading could close Cutaway. It can't now.
- Going back a segment after removing segments from a running rundown could close Cutaway.
- An audio input whose first sound arrived a few milliseconds into the mixer's block could close Cutaway (most likely when adding an input). Fixed.
- The update notice shows what's new as plain text, not the download table.

**Lighter and quicker**
- Only the cameras a frame actually shows (on air, in preview, on the multiview, in the vertical version) are copied to the graphics card for it, which saves a lot with several 4K cameras.
- Cameras open side by side when Cutaway starts, so the show is ready sooner.
- The turning test pictures take a fraction of the work they did.
- Automatic switching reads only its own settings each moment, not the whole show's.
- With the remote, OSC and MIDI all off, Cutaway no longer prepares their updates.
