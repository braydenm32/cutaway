## Download

| For | File |
|---|---|
| Mac with Apple Silicon (M1 or later), macOS 13 or newer | **Cutaway-0.8.0-macos-arm64.zip** |
| Windows 11, 64-bit | **Cutaway-0.8.0-windows-x64.zip** |
| Stream Deck (Mac or Windows) | **Cutaway.streamDeckPlugin** |

The apps aren't signed yet, so the first launch takes one extra step. **Mac:** unzip, move Cutaway.app to Applications and open it; when macOS refuses, open System Settings → Privacy & Security and choose **Open Anyway**. **Windows:** unzip anywhere and run Cutaway.exe; when Windows says it "protected your PC", choose **More info → Run anyway**.

Settings, shows and recordings carry over from 0.7 and 0.6. The Stream Deck plugin hasn't changed.

## New in 0.8.0

**Update from inside Cutaway**
- When a newer version comes out, **Update now** in the header's notice downloads it in the background (carry on with the show meanwhile), checks it against the release's fingerprints, and runs it once to make sure it starts.
- Then choose **Restart to update** (it waits until recording and streaming have stopped) or **When I quit**. Cutaway puts the new version in place and keeps your settings and shows.
- The previous version is kept until the new one has run for a few seconds. If the new one doesn't start, Cutaway puts the old one back by itself and says so.
- To have updates arrive on their own: Settings → General & shows → Updates → **download it by itself, and put it in when I quit**.
- If Cutaway can't change its own folder (for example, a Mac account without administrator rights), the notice takes you to the download page instead. On Windows, an update that changes the virtual camera asks you to reinstall it in Settings → Screens & webcam (administrator rights, once).

This version is still a manual download; the updates after it can come through the button.

The full guide is in the [README](https://github.com/braydenm32/cutaway#readme).
