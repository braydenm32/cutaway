New to Cutaway? The apps aren't signed yet, so the first launch takes one extra step. **Mac:** unzip, move Cutaway.app to Applications and open it; when macOS refuses, open System Settings → Privacy & Security and choose **Open Anyway**. **Windows:** unzip anywhere and run Cutaway.exe; when Windows says it "protected your PC", choose **More info → Run anyway**.

Settings, shows and recordings carry over.

## Before you update: stream keys move to the Keychain

Stream keys, passwords and sign-in tokens now live in the **Keychain** on a Mac, or **Credential Manager** on Windows, instead of the settings file. Cutaway moves them the first time it saves your settings; you don't need to do anything. A Mac may ask once after each update to let Cutaway use them: choose **Always Allow**. **Export settings** now leaves them out, so an exported file is safe to share, but you'll need to type the keys in again on another computer.

## New in 0.9.5

**Running the show**
- **A tidier right-hand column.** Click a panel's title (Stream, Rundown, Guests and so on) to fold it down to one line, and drag a title to move that panel. Each show remembers its own layout.
- **Names that follow people.** Give each camera or tile the name and role of the person in it (Settings → Sources → **Name title**), then add **＋ Who's on air** in Settings → Graphics. One key shows the title of whoever is on screen, and it changes when you switch. Tick **By itself** to name each person automatically when they first come on.

**Guests**
- **Guest links that stay the same.** Choose **Tailscale** in Settings → Guests and each guest's link stays the same from show to show, so you can send it days ahead. Install Tailscale (free) and sign in once.

**Recording and editing**
- **A recording without graphics.** Tick **Program without graphics** in Settings → Recording → For editing to also record `Program_Clean`: the same cuts and transitions, with no titles, logos, captions or tickers. The DaVinci Resolve and Premiere projects cut to it, so you can add your own titles in the edit.

**Getting started and getting help**
- **Your first show.** A short guide opens the first time Cutaway runs: cameras, microphone, where recordings go, going live, the pre-show check and a test recording. Open it any time with **?** at the top.
- **Problem report.** Settings → Diagnostics → **Save a problem report…** saves one .zip to send when something goes wrong: the log, the last take's note, your settings and devices, with stream keys and passwords taken out.

**Windows**
- **Less work for the processor.** Videos, network sources, guests, replays and MJPEG webcams are now decoded on the graphics card, falling back to the processor if that fails. Screen captures take about a third of the processor time they did.
