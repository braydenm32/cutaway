## Download

| For | File |
|---|---|
| Mac with Apple Silicon (M1 or later), macOS 13 or newer | **Cutaway-0.7.1-macos-arm64.zip** |
| Windows 11, 64-bit | **Cutaway-0.7.1-windows-x64.zip** |
| Stream Deck (Mac or Windows) | **Cutaway.streamDeckPlugin** |

The apps aren't signed yet, so the first launch takes one extra step. **Mac:** unzip, move Cutaway.app to Applications and open it; when macOS refuses, open System Settings → Privacy & Security and choose **Open Anyway**. **Windows:** unzip anywhere and run Cutaway.exe; when Windows says it "protected your PC", choose **More info → Run anyway**.

Settings, shows and recordings carry over from 0.7.0 and 0.6. The Stream Deck plugin hasn't changed.

## New in 0.7.1

- **Readable on a light-mode computer.** On a Mac or PC set to light mode, the Settings window, its drop-downs and some dialogs turned white under Cutaway's light text, so parts of them were hard or impossible to read. Cutaway now stays dark whatever the computer's appearance.
- **Larger text in Settings.** Settings' text, drop-downs and explanations are a size up from the main window's. (Settings → General & shows → Interface size still makes the whole app bigger or smaller.)

Everything new in 0.7 (changing sources mid-show, the starting screen, the condensed Settings with an explanation for every setting) is in the [0.7.0 notes](https://github.com/braydenm32/cutaway/releases/tag/v0.7.0).

The full guide is in the [README](https://github.com/braydenm32/cutaway#readme).
